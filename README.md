# Extractor 📦

Ein natives macOS-Tool zum Entpacken und Analysieren von Archiven. Es nutzt unter der Haube die Power von 7zip, bietet aber eine benutzerfreundliche Oberfläche für den Mac.

## 🚀 Features
* **Drag & Drop:** Archive einfach in die App ziehen.
* **Format-Support:** Unterstützt diverse Formate via 7zip-Integration.
* **File Inspection:** Vorschau von Archiv-Inhalten vor dem Entpacken.

## 🛠 Technologien
* Swift (macOS App)
* AppKit / SwiftUI
* Shell-Integration (Process/Pipe)
